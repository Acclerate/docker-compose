❯ mysql: [Warning] Using a password on the command line interface can be        
  insecure. 有什么风险                                                          

● 这只是一个提示，不是错误，意思是密码明文出现在命令行中，有两个风险：

  1. 进程列表可见 — 其他用户执行 ps aux 能看到你的完整命令（包含密码）
  2. Shell 历史记录 — 密码会保存在 ~/.bash_history 中

  实际影响： 你是在 Docker 容器内执行、服务器只有你用，风险很低，可以忽略。

  如果介意，以后可以用交互方式登录（不在命令行带密码）：

  docker exec -it doris-fe mysql -uroot -h127.0.0.1 -P9030 -p

  输入密码时不会显示，也不会记录到历史。
